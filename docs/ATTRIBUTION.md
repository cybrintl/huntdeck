# Data source attribution and terms

HuntDeck's runtime uses only static snapshots generated by GitHub Actions. This file records sources used by the current pipeline and identifies planned sources. Check the upstream terms before redistributing snapshots or using the data commercially; availability without authentication does not imply unrestricted reuse.

## Planned / not currently indexed

These sources are described in the product specification but are not yet part of the production snapshot pipeline:

- CVE.org CVE detail records
- Bambenek OSINT feeds
- botvrij.eu and CIRCL MISP feeds
- ransomware.live group intelligence
- Elastic detection-rule metadata (Elastic License v2; metadata and links only)
- Splunk security_content (CC BY-NC; metadata and links only)
- Atomic Red Team test metadata (MIT)
- Additional incident-response and threat-research RSS feeds

No source requiring an API key, account registration, or paid subscription is fetched by the current pipeline. For example, current URLhaus and ThreatFox bulk APIs require an abuse.ch authentication key, so they are not included. Sources are fetched in the Actions pipeline, not directly from the user's browser.

IPsum is also not currently ingested: it aggregates dozens of upstream blocklists, and the repository's software license does not by itself establish redistribution rights for every upstream dataset. Future IOC additions should be evaluated for source freshness, signal context, false-positive risk, authentication requirements, and data reuse terms—not just feed availability.

IOC snapshots include community feeds with distinct reuse terms. In particular, the DShield Recommended Block List is CC BY-NC-SA 2.5 and the OpenPhish community feed has commercial-use restrictions. HuntDeck preserves source names and links, but its Apache-2.0 code license does not grant rights to these datasets. Review each source's current terms before redistribution or commercial use.

RSS records are limited to selected headlines, short feed-provided summaries, tags, publication dates, extracted references, and source links. These publisher-provided records are not HuntDeck-authored content; attribution and linking do not replace review of each publisher's reuse terms.
