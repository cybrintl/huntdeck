# Data source attribution and terms

HuntDeck's runtime uses only static snapshots generated by GitHub Actions. This file records sources used by the current pipeline and identifies planned sources. Check the upstream terms before redistributing snapshots or using the data commercially; availability without authentication does not imply unrestricted reuse.

## Current pipeline

| Source | Snapshot | Attribution and terms |
|---|---|---|
| CISA Known Exploited Vulnerabilities Catalog | `kev.json` | U.S. government source. Attribute CISA; review the catalog's notices for third-party content. [Catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) |
| FIRST EPSS | `epss.json` | FIRST EPSS project. Scores are filtered to KEV CVEs plus the top 5,000 EPSS scores to control snapshot size. [EPSS](https://www.first.org/epss/) |
| MITRE ATT&CK CTI | `techniques.json` | MITRE ATT&CK is licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Attribute The MITRE Corporation and link to [ATT&CK](https://attack.mitre.org/). |
| OpenPhish Community Feed | `iocs.json` | Community feed with terms that restrict commercial use. Attribute OpenPhish and follow its [terms](https://openphish.com/terms.html). |
| DShield Recommended Block List | `iocs.json` | Attribute SANS Internet Storm Center/DShield. The list is distributed under [CC BY-NC-SA 2.5](https://creativecommons.org/licenses/by-nc-sa/2.5/); non-commercial and share-alike terms apply. |
| CINS Army | `iocs.json` | Attribute CINS Army and follow the current [site terms](https://cinsscore.com/). |
| blocklist.de | `iocs.json` | Attribute blocklist.de and follow its [service terms](https://www.blocklist.de/en/). |

## Planned / not currently indexed

These sources are described in the product specification but are not yet part of the production snapshot pipeline:

- CVE.org CVE detail records
- Bambenek OSINT feeds
- botvrij.eu and CIRCL MISP feeds
- ransomware.live group intelligence
- Elastic detection-rule metadata (Elastic License v2; metadata and links only)
- Splunk security_content (CC BY-NC; metadata and links only)
- Atomic Red Team test metadata (MIT)
- Additional incident-response and threat-research RSS feeds

No source requiring an API key, account registration, or paid subscription is in scope. Sources are fetched in the Actions pipeline, not directly from the user's browser.
